Saat memuat
1 · Unggah file (.xlsx atau .csv)
2 · Tempel URL Google Sheet

Sheet harus dipublikasikan: File → Bagikan → Publikasikan ke web → CSV. Kalau gagal (diblokir), pakai cara unggah file atau tempel CSV.

3 · Tempel teks CSV

Kolom yang dikenali: nama, jenis (masjid/musala), alamat, lat, lng, opsional rating, jumat (ya/tidak), kapasitas, fasilitas (dipisah titik-koma). Boleh juga satu kolom gmaps berisi link/koordinat Google Maps sebagai ganti lat & lng. File hasil salin dari Google Maps (berisi kolom link) juga otomatis dikenali.

Cara pakai & keterangan

Radar berpusat di Alun-alun Wonosari (titik biru muda) dan otomatis memperbesar ke area terdekatmu. Hijau = masjid, oranye = musala, cincin pink = dipilih, titik pink berdenyut = lokasimu.

Urutkan dengan Terdekat / Rating / A–Z, saring Favorit, Lokasi memusatkan ke posisimu. Radar menampilkan titik terdekat saja; daftar bisa lebih panjang.

Database bisa diganti/diperbarui lewat panel Perbarui database — unggah spreadsheet, tempel CSV, atau muat dari Google Sheet. Tambah satu titik lewat Tandai, atau ambil dari OpenStreetMap.

Catatan. Database bawaan berisi 230 masjid Gunungkidul hasil rekap dari Google Maps (nama, koordinat, & rating apa adanya) — mungkin ada yang belum lengkap, ganda, atau berubah; perbarui lewat panel database. Titik pusat Alun-alun Wonosari dari Plus Code 2JM2+W8V. Jarak dihitung garis lurus. Info salat Jum'at hanya ada bila kamu isi sendiri. GPS & sebagian fitur perlu https:// (aman di Vercel).
